## Current evidence boundaries

Ocean trajectories use pinned model currents and hypothetical geometry; the central 2/6 versus flanking 4/6 result is an illustrative what-if, with the original zero-entry tie preserved. Numerical sensitivity is a separate diagnostic and not physical accuracy or ML improvement. Camera preview is not calibrated tank drift or a physical trial. Chalk explains exact evidence but does not replace deterministic physics; provider readiness is not a live response. Photon acceptance is not necessarily delivery. Historical protocols and test counts retain their dates and scope.
