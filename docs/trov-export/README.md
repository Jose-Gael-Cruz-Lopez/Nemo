## Current evidence boundaries

Ocean trajectories use pinned model currents and hypothetical geometry; the central 2/6 versus flanking 4/6 result is an illustrative what-if, with the original zero-entry tie preserved. Numerical sensitivity is a separate diagnostic and not physical accuracy or ML improvement. The final local post-guard checkpoint passed 1,365 Python, 191 frontend and 137 guarded HTTP checks, with six expected external/physical blockers, plus lint/types/build; a separate bounded live Chalk REPORT cites final comparison/method identities. This is not a hosted-CI/deployment pass or complete physical validation. The matched-current study is DRAFT: only metadata were retrieved, with no new study trajectories, current-vector values, fits or scores. Camera preview is not calibrated tank drift or a physical trial. Chalk explains exact evidence but does not replace deterministic physics; provider readiness alone is not a live response. Photon acceptance is not necessarily delivery. Historical protocols and test counts retain their dates and scope.
